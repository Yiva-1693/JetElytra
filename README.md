# Jet Elytra

为 Minecraft 鞘翅加入燃料推进：滑翔时按住前进键加速，用烟花火箭补充燃料，按潜行键退出滑翔。

沿用原版鞘翅和烟花火箭，无需合成额外装备。

## 运行环境

| 项目 | 版本 |
| --- | --- |
| 模组 | 1.3.1 |
| Minecraft | 1.20.1 |
| 加载器 | Minecraft Forge，当前构建使用 47.4.28 |
| Java | 17 |
| 安装位置 | 客户端和服务端均需安装 |

当前项目面向 Forge 1.20.1；其他 Minecraft 版本及其他加载器的兼容性未经验证。

## 安装

1. 准备 Minecraft 1.20.1 的 Forge 游戏实例。
2. 将构建得到的 `Jet Elytra-1.3.1.jar` 放入该实例的 `mods/` 文件夹。
3. 多人游戏时，在服务端 `mods/` 中安装相同版本的模组，并让所有玩家使用相同版本。
4. 启动游戏，装备原版鞘翅后即可使用。

从源码构建的方法见下方“开发与构建”。

## 操作

以下为默认键位。修改原版“前进”“潜行”“使用物品”绑定后，按修改后的键位操作。

| 操作 | 效果 |
| --- | --- |
| 按原版方式展开鞘翅 | 进入滑翔；模组不会自动起飞 |
| 滑翔时按住 `W` | 燃烧燃料，沿视线方向推进 |
| 松开 `W` | 停止烧油，剩余推力逐渐衰减 |
| 滑翔途中重新按下 `Shift` | 立即退出滑翔并停止推进，随后自由下落 |
| 滑翔时手持烟花火箭并使用，默认右键 | 消耗一支火箭补充燃料，替代原版空中烟花推进 |

- 起飞前已经按住潜行键，不会在展开鞘翅时自动取消；需要在滑翔途中重新按下。
- 潜行键支持键盘、鼠标和扫描码绑定；聊天框等界面内的输入不会触发取消滑翔。
- 地面烟花发射、弩和发射器不在空中补油拦截范围内。
- 创造模式下的鞘翅滑翔同样消耗燃料和补油用的火箭。

## 燃料与推进

默认油箱容量为 **200 点**，推进每秒消耗 **25 点**，不补给时满箱约可连续推进 **8 秒**。

从零推力状态启动推进需要至少 **20 点**燃料；已经在推进时可继续消耗至燃料耗尽。停止推进后等待 **30 tick（1.5 秒）**，随后按当前状态恢复燃料：

| 状态 | 默认恢复速度 |
| --- | --- |
| 仍在鞘翅滑翔 | 10 点/秒 |
| 不在滑翔，例如落地或走路 | 20 点/秒 |

首次进入世界和死亡重生时获得满油箱，剩余燃料会随玩家数据保存。

默认推进目标速度为 **33.5 格/秒**。推力从当前速度接续增加，增量由 `accelerationTicks` 决定；默认 45 tick 对应从零增加至目标推力约 **2.25 秒**。俯冲等方式获得的更高滑翔速度不会被强行压到该目标值。

上述秒数按服务器正常运行在 20 TPS 时计算。

### 烟花补油

| 烟花火箭飞行时间 | 每支默认补充燃料 |
| --- | --- |
| 1 | 50 点 |
| 2 | 100 点 |
| 3 | 150 点 |

滑翔时，燃料降到 **50 点及以下**会自动寻找火箭补油。搜索顺序为：**主手 → 副手 → 快捷栏 → 背包其他位置**。

手动补油在油箱已满时不会消耗火箭；油箱未满时会消耗整支火箭，超过容量的补充值不会保留。

### 燃料显示

生存和冒险模式下，滑翔期间用蓝色燃料条和燃料数字替换经验条及等级数字。退出滑翔后，燃料未满时继续显示；补满后停留约 1 秒，再恢复原版经验显示。经验数据本身不会被修改。

## 配置

配置由服务端保存，并同步到客户端。首次加载世界后生成：

- 单人游戏：`saves/<存档名>/serverconfig/jet_elytra-server.toml`
- 独立服务端：`<世界目录>/serverconfig/jet_elytra-server.toml`，默认世界目录为 `world/`

建议退出世界或停止服务端后修改，再重新加载。生成的 TOML 文件包含中文说明和允许范围。

| 配置项 | 默认值 | 作用 |
| --- | --- | --- |
| `fuelCapacity` | `200.0` | 油箱容量 |
| `fuelConsumptionPerSecond` | `25.0` | 推进每秒消耗燃料；0 表示不消耗 |
| `fuelRefillInFlightPerSecond` | `10.0` | 滑翔时每秒自动恢复燃料 |
| `fuelRefillOutOfFlightPerSecond` | `20.0` | 非滑翔时每秒自动恢复燃料 |
| `refillDelayTicks` | `30` | 停止推进后的恢复延迟，单位 tick |
| `minFuelToStart` | `20.0` | 从零推力状态启动所需最低燃料 |
| `autoRefuelThreshold` | `50.0` | 滑翔中触发自动烟花补油的燃料阈值 |
| `maxSpeedBlocksPerSecond` | `33.5` | 推进目标速度，单位格/秒 |
| `accelerationTicks` | `45` | 推力从零增加至目标值的 tick 数，也决定松键衰减速率 |
| `particleCount` | `2` | 推进时每 tick 生成的尾迹粒子数量；0 关闭 |
| `particleSpread` | `0.2` | 尾迹粒子散布范围 |
| `syncIntervalTicks` | `5` | 燃料定期同步间隔；燃料变化较大时会提前同步 |
| `fireworkFuelFlight1` | `50` | 飞行时间 1 的火箭补充值 |
| `fireworkFuelFlight2` | `100` | 飞行时间 2 的火箭补充值 |
| `fireworkFuelFlight3` | `150` | 飞行时间 3 的火箭补充值 |

### 1.3.1 已知限制

- `autoRefuelThreshold = 0` 仍会在燃料恰好为 0 时触发自动补油，不能完全关闭此功能。
- 自动补油阈值大于等于油箱容量时，满油也可能消耗火箭；将火箭补充值设为 0，同样可能白白消耗火箭。建议保持阈值小于容量，火箭补充值大于 0。
- 创造模式下的燃料条尚不能正常显示，但燃料和补给消耗仍然生效。

## 开发与构建

准备 JDK 17，使用项目自带的 Gradle Wrapper。首次构建需要联网下载依赖。

Windows PowerShell：

```powershell
.\gradlew.bat build
```

Linux / macOS：

```bash
bash ./gradlew build
```

构建产物位于：

```text
build/libs/Jet Elytra-1.3.1.jar
```

启动开发客户端或服务端：

```powershell
.\gradlew.bat runClient
.\gradlew.bat runServer
```

首次启动开发服务端需要按 Minecraft 的要求处理 EULA。
